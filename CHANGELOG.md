## [0.0.1] - 2025-12-22

- Initial release of **Flutter Best Theme**:
  - Dark theme optimized for Flutter development
  - Clear widget hierarchy for nested widgets
  - Vibrant bracket pair colors
  - Highlighted async, state management, navigation, strings, numbers, and booleans
  - Comfortable background and muted comments for long coding sessions
